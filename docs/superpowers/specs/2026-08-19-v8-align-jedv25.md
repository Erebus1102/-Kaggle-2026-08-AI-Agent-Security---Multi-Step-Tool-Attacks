# V8 设计:对齐 jed-v25 核心配置(PROBE_HOPS=8 + 分流模板)

日期:2026-08-19
状态:待批准
前置:V7 结果 51.7、探针 E 54.1、探针 F 53.5(全部低于探针 D 65.2)、jed-v25 源码逐行对比

## 1. 背景与动机

V7/探针 E/探针 F 全部负收益,但 jed-v25(nctuan)同配置能到 90.6。逐行对比源码找到根因:**PROBE_HOPS**。

| 参数 | jed-v25 | 我们 | 后果 |
|---|---|---|---|
| PROBE_HOPS | 0(=8 hop) | 1 | 我们用 1-hop probe 验证,回放 8-hop → 生成≠回放漂移 |
| SLOW_MULTIPOST_N | 1(单 post) | 4 | multi4 负收益(V6/V7 验证) |
| MARGIN_FLOOR_MIN | 4.0 | 30.0 | 我们 edge-prune 过保守 |
| FILL_BUDGET_FRAC | 0.95 | 0.85 | 我们 fill 预算浪费 10% |

### 机制(漂移解释一切)

- **hops=1 probe**:模型在 1 hop 内 post 才 fire 收录。forged 立即 post(漂移小),plain 需要多 hop 才 post(1 hop 截断 → 收录的是"不完整执行"的候选 → 回放 8 hop 行为漂移 → fire 率低)。
- **hops=8 probe**:完整验证 8-hop 回放行为,收录的候选和回放行为一致,fire 率 ~100%。

这解释了全部 8 个数据点:
- 探针 D 65.2 = forged + hops=1(forged 漂移小,勉强可用)
- 探针 E 54 = plain + hops=1(plain 漂移大,失效)
- jed-v25 90.6 = plain + hops=8(plain 完整验证,生效)+ 激进 fill 参数

**gemma plain 不是错的,是 hops=1 让它失效。hops=8 下 plain 才生效。**

## 2. 设计(对齐 jed-v25)

### 2.1 PROBE_HOPS 1 → 8

`PROBE_HOPS: Final[int] = 1` → `8`。probe 用完整 8 hop,elapsed 是完整回放时间,replay_cost = elapsed × 1.0 准确,消除生成≠回放漂移。

代价:probe 更慢(~2x),fill 候选更少。但候选 fire 率从 ~70% 提到 ~100%,净有效候选更多。

### 2.2 分流模板(与 jed-v25 一致)

- fast 行(gemma):plain `post_msg`(V7 已改,hooks=8 下才生效)
- slow 行(gpt_oss):forged 单 post `forged_post_msg`(multi4 已证伪,回退单 post)

run() 主填充改为:

```python
main, live_ok = _fill(
    env, main_deadline, _url_stream(),
    post_msg,                          # fast: plain (hops=8 下生效)
    replay_cap_s=REPLAY_SAFE_FRAC * REPLAY_BUDGET_S,
    make_multipost=None)               # slow: 也单 post(plain)
```

等等——jed-v25 的 slow 行是 forged 单 post,不是 plain。需要 _fill 支持"slow 用不同单 post 模板"。最简:复用 V6 的 make_multipost 参数,传 `lambda urls: forged_post_msg(urls[0])`(slow 行 forged 单 post)。

### 2.3 参数对齐

| 参数 | 现在 | V8 |
|---|---|---|
| EDGE_MARGIN_FLOOR_S | 30.0 | **4.0** |
| MARGIN_FRAC | 0.15 | **0.05**(fill 用 95% 预算) |

edge-prune 从 `max((2.5/1.5)×mean, FLOOR)` 保持均值逻辑,floor 降到 4.0。

### 2.4 保持不变

- REPLAY_SAFE_FRAC 0.97、MULTIPOST_REPLAY_COEF 1.0(无关了,multi4 弃用)
- 静态兜底 plain、deputy 2%、_probe/_finalize/streams/硬约束

## 3. 预期

对标 jed-v25 84±5(其自述 fire-rate-bound)。若 hops=8 漂移假设成立,V8 应达 **75-85**,首次进入主部队。

## 4. 测试

1. PROBE_HOPS == 8 常量断言
2. _fill 单变体 + slow 用 forged 单 post(fast plain / slow forged)
3. EDGE_MARGIN_FLOOR_S == 4.0、MARGIN_FRAC == 0.05 断言
4. 集成测试:fake env 快行 → plain;慢行 → forged 单 post
5. 端到端:validate + deterministic 冒烟

## 5. 风险与判定树

1. **hops=8 probe 慢**:fill 候选少,若候选数不足填满回放窗口,分数反降。但 jed-v25 实证 84±5,风险可控。
2. **判定树**:V8 ≥75 → hops=8 漂移假设成立,继续对齐参数冲 90+;V8 60-75 → 部分成立,继续差分;V8 <60 → hops=8 不是关键,回退探针 D。
